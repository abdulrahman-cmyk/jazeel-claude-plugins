# Jazeel Brand — إضافة صوت العلامة

إضافة رسمية تطبّق صوت جزيل في كتابة ومراجعة المحتوى العربي.

## المحتوى

| المهارة | ماذا تفعل |
|---|---|
| `jazeel-voice` | تكتب وتراجع محتوى جزيل بصوت العلامة: منشورات السوشال، رسائل واتساب، نصوص Push، عروض الضيافة و B2B، إعلانات الأسعار، والردود على الشكاوى والتأخير. |

## الإصدارات

**1.4.0 — 27 أغسطس 2026** · دليل v2.4

- **استثناء أسماء المنتجات المسجّلة من القاموس** — الاسم كما هو في النظام ولو خالف القاموس («قهوة سعودية فاخرة»، «بوكس الفخامة»)، والاستثناء للاسم وحده لا لبقية النص.

**1.3.0 — 26 أغسطس 2026** · دليل v2.3

- **رسالة واتساب = رسالة كاملة لا تنبيه** — ببنية من ستة عناصر ونموذج جاهز، والطول 6–10 أسطر.
- **بنية تنبيه التطبيق** — عنوان التنبيه (2–5 كلمات) ونص الرسالة (5–15 كلمة)، بلا تكرار بينهما.

**1.2.0** · دليل v2.2 — لم تُرفع للمستودع؛ محتواها مضمَّن في 1.3.0.

**1.1.0** · دليل v2.1

- تصحيح ادّعاءين غير دقيقين عن المنتج: حُذف «قوام يمسك ولا يذوب في اليد» و«تحميص فاتح».
- **قاعدة «خذ الفكرة، لا الصياغة»** — لا تُحفظ لهجة النص الوارد؛ يُستخرج المعنى ويُعاد الكتابة من الصفر بسعودي أبيض. تشمل الترجمة من الإنجليزية، ومعها حارس «الإزالة لا الإضافة».
- **قاعدة الادّعاء** — لا اختراع أرقام أو مكوّنات أو طرق تحضير أو أوصاف أداء؛ يُترك فراغ محدد وتُطلب المعلومة.
- **قسم طريقة العمل** — خطوات ملزمة قبل التسليم، وسلوك محدد عند مراجعة نص جاهز.
- تخفيف سياسة الإيموجي مع سقف صريح، وتوسيع «هذا جزيل / مو جزيل» إلى ستة أنماط خطأ مع سطر «الفرق».
- إغلاق بند حق الرد وقت الأزمة: للمدير.

## التركيب

**من داخل Claude / Cowork:** افتح ملف `.plugin` واضغط تثبيت.

**من مستودع جيت هب:**

```
/plugin marketplace add abdulrahman-cmyk/jazeel-claude-plugins
/plugin install jazeel-brand@jazeel-claude-plugins
```

## التحديث التلقائي للفريق

أضف إلى `.claude/settings.json` في مستودع الفريق:

```json
{
  "extraKnownMarketplaces": {
    "jazeel-claude-plugins": {
      "source": { "source": "github", "repo": "YOUR-ORG/jazeel-claude-plugins" },
      "autoUpdate": true
    }
  },
  "enabledPlugins": {
    "jazeel-brand@jazeel-claude-plugins": true
  }
}
```

بدون `autoUpdate` يحتاج كل مستخدم أن يشغّل `/plugin marketplace update jazeel-claude-plugins` يدويًا.
